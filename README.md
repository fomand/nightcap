# The Nightcap support

A static support website for The Nightcap.

## Publish with GitHub Pages

In Settings → Pages, select **Deploy from a branch**, choose **main** and **/ (root)**, then click **Save**.

Once GitHub finishes publishing, the support URL is https://fomand.github.io/nightcap/.

Support contact: fomand@gmail.com.

The page uses no JavaScript, analytics, cookies, or external fonts.
